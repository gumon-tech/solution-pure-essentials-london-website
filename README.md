# Pure Essentials London website

Static site for a London salon and clinic, built with Next.js and published on GitHub Pages at
https://pel.gumon.io until the clinic's own domain is switched over.

- Room: PWEB (code). Content, structure and rulings come from the PEL line lead.
- Every service and price lives in `data/services.json`. Edit prices there; the site reads it.
- Start with `HANDOFF.md`.
